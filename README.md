# 选项一：控制台扫雷游戏 (Minesweeper)## 1. 详细基础需求（及格线）### 网格与地雷模型：- 支持至少 9×9 规格（10 颗雷），网格单元需包含三种状态翻（Covered ）、已翻开（Revealed）、插旗标记（Flagged）。- 坐标系统清晰（行号 1~9，列号 1~9 或字母坐标）。### 首步安全保底机制：- 玩家首次翻开的位置绝对不能为地雷（在用戶首次输入有效坐标后，再动态随机布  雷，若落在首击坐标则重抽或顺延）。### 交互指令解析：- 支持两种核心操作，指令格式明确（例如：o x y 或 open x y 翻开格子；f x y 或  flag x y 切换插旗状态）。- 当格子已翻开时不可再次插旗或翻开；当格子处于插旗状态时，翻开操作需给出提  示或被锁定。### 空白级联自动展开（Cascade Reveal）：- 当翻开的格子周围地雷数为 0 时，必须使用算法（广度优先搜索 BFS、深度优先 搜索 DFS 或队列递归）自动级联展开其周围 8  个相邻的未翻开格子，直到遇到数  字格边缘为止。### 胜负结算与棋盘展示：- 踩雷时游戏结束，揭开所有地雷位置供玩家核对；当所有非地雷格子全部被翻开时  判定获胜。- 每次操作后清爽渲染棋盘，要求行列对其整⻬。## 2. 进阶加分项（选做）- 支持终端 ANSI 颜色区分数字（1 蓝、2 绿、3 红等）。- 游戏耗时计时（开始到结束统计秒数）。- 自定义难度选择（初级、中级、高级）。## 3. 伪代码主流程- 初始化棋盘 - 标记 isFirstOpen = true - while(true)- 打印棋盘 - 读取玩家一行输入 - 解析指令 - if 是open指令： - if isFirstOpen： - placeMine 布雷 - calcAroundMine()- isFirstOpen = false - 执行翻开逻辑 + BFS - 判断是否踩雷，踩雷就结束循环 - 判断是否胜利，胜利就结束循环 - else if 是flag指令： - 切换插旗状态
